- **React projects**, including the iNotebook frontend in [`inotebook/`](./inotebook).
- **MongoDB and Mongoose** learning, including database connection work and iNotebook backend development.

## Run the iNotebook frontend

```bash
cd inotebook
npm install
npm start
```

The frontend runs at `http://localhost:3000`.

The backend is in [`inotebook/backend/`](./inotebook/backend). Copy `.env.example` to `.env`, add the MongoDB connection details, install its dependencies, and start the Express server with `node index.js`.
